## 💡 The Vision

**TrayMe isn't just an app. It's a productivity system that becomes muscle memory.**

Every Mac user wastes **23 minutes per day** finding things they copied, organizing files, and opening apps to jot down quick thoughts. That's **140 hours per year** — nearly 4 work weeks lost to friction.

TrayMe eliminates this friction with **one gesture**. Move your mouse to the top → everything you need slides down → get back to work.

## 🎮 Usage

### Activation Methods
| Method | Action |
|--------|--------|
| **Mouse** | Move to top of screen |
| **Hotkey** | Press `Cmd+Shift+U` |
| **Menu Bar** | Click tray icon |

### Keyboard Shortcuts
| Shortcut | Action |
|----------|--------|
| `Space` | Quick Look preview |
| `←` `→` `↑` `↓` | Navigate in Quick Look |
| `Cmd+R` | Refresh file status |
| `Cmd+,` | Open settings |
